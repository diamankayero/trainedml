Multicollinearity

Multicollinearity analysis utilities for trainedml.

This module provides functions for computing the Variance Inflation Factor (VIF) to assess multicollinearity among features in a pandas DataFrame.

Mathematical context

  • VIF: $VIF_j =

rac{1}{1 - R_j^2}$

Exemples

>>> from trainedml.viz.multicollinearity import vif_summary
>>> vif = vif_summary(df)
>>> print(vif)

Compute the Variance Inflation Factor (VIF) for each feature.

Paramètres:

Renvoie:
