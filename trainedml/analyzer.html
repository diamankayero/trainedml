DataAnalyzer

Data analysis and exploratory statistics for trainedml.

This module provides the DataAnalyzer class, which offers a suite of methods for descriptive statistics, distribution analysis, correlation, missing values, outliers, target analysis, boxplots, bivariate analysis, normality, multicollinearity, and profiling.

Math context

  • Correlation: Pearson, Spearman, Kendall

  • Outlier detection: IQR, Z-score

  • Normality: Shapiro-Wilk, D’Agostino, Anderson-Darling

  • Multicollinearity: Variance Inflation Factor (VIF)

Exemples

>>> from trainedml.analyzer import DataAnalyzer
>>> analyzer = DataAnalyzer(df)
>>> stats = analyzer.distribution()
>>> print(stats)
>>> corr = analyzer.correlation(method='spearman')
>>> print(corr)
>>> out = analyzer.outliers(method='zscore', threshold=3)
>>> print(out)
>>> norm = analyzer.normality()
>>> print(norm)
>>> report = analyzer.profiling()
>>> print(report['describe'])

Exploratory data analysis and statistics.

Provides a suite of methods for descriptive statistics, distribution analysis, correlation, missing values, outliers, target analysis, boxplots, bivariate analysis, normality, multicollinearity, and profiling.

Paramètres:

data (pandas.DataFrame) – The dataset to analyze.

data

The underlying data.

Type:

pandas.DataFrame

Exemples

>>> from trainedml.analyzer import DataAnalyzer
>>> analyzer = DataAnalyzer(df)
>>> stats = analyzer.distribution()
>>> print(stats)

>>> corr = analyzer.correlation(method='spearman')
>>> print(corr)

>>> out = analyzer.outliers(method='zscore', threshold=3)
>>> print(out)

>>> norm = analyzer.normality()
>>> print(norm)

>>> report = analyzer.profiling()
>>> print(report['describe'])

Notes

  • All methods return pandas objects or dicts for easy integration with pandas workflows.

  • For plotting, returned objects are matplotlib figures.

Compute the correlation matrix between features.

Paramètres:

Notes

outliers(method='iqr', threshold=1.5, **kwargs)[source]

Detect outliers in the dataset.

Paramètres:

  • method (str, default='iqr') – Outlier detection method (“iqr”, “zscore”).

  • threshold (float, default=1.5) – Threshold for outlier detection (IQR multiplier or Z-score cutoff).

  • **kwargs – Additional arguments.

Renvoie:

Dictionary per column with keys “count”, “indices”, “lower_bound”, “upper_bound”.

Type renvoyé:

dict

Notes

IQR method: $Q_1 = 25%$ percentile, $Q_3 = 75%$ percentile $IQR = Q_3 - Q_1$ Outlier if $x < Q_1 - k cdot IQR$ or $x > Q_3 + k cdot IQR$

Exemples

>>> out = analyzer.outliers()
>>> print(out)
>>> out = analyzer.outliers(method='zscore', threshold=3)
>>> print(out)
