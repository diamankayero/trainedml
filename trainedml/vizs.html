Vizs (visualisations de base)

Base class for trainedml visualizations.

This module provides the Vizs class, which serves as a base for all visualization classes in trainedml. It defines the interface and common attributes for visualizations.

Exemples

>>> from trainedml.viz.vizs import Vizs
>>> class MyViz(Vizs):
...     def vizs(self):
...         # custom plotting code
...         pass
class trainedml.viz.vizs.Vizs(data, save_path: str | None = None)[source]

Bases : object

Classe de base pour toutes les visualisations. Toutes les visualisations doivent hériter de cette classe et surcharger la méthode vizs().

_data

DataFrame pandas contenant les données

_figure

Figure matplotlib générée

_save_path

Chemin optionnel pour sauvegarder automatiquement la figure

property figure

Retourne la figure générée.

save(path: str | None = None, dpi: int = 150, **kwargs) → str | None[source]

Sauvegarde la figure dans un fichier.

Paramètres:

  • path (str, optional) – Chemin du fichier. Si None, utilise self._save_path

  • dpi (int) – Résolution de l’image (défaut: 150)

  • **kwargs – Arguments supplémentaires passés à plt.savefig()

Renvoie:

Chemin du fichier sauvegardé, ou None si échec

Type renvoyé:

str

Lève:

ValueError – Si aucun chemin n’est spécifié et _save_path est None

property save_path: str | None

Retourne le chemin de sauvegarde configuré.

vizs()[source]

Méthode à surcharger dans les classes filles pour générer la visualisation. Appelle automatiquement save() si un save_path a été défini.
