Détection de tâche

Task type detection (classification vs regression) for trainedml.

This module centralizes the heuristic used by the Trainer, the CLI, the Benchmark, and trainedml.compare() to determine whether a target corresponds to a classification or a regression task.

Heuristic

  • Non-numeric target (text, categorical, StringDtype…) -> classification

  • Integer target with few unique values (<= 20) -> classification

  • Otherwise -> regression

Exemple

>>> from trainedml.tasks import detect_task
>>> detect_task(pd.Series(["setosa", "versicolor"]))
'classification'
>>> detect_task(pd.Series([1.5, 2.3, 4.8]))
'regression'
trainedml.tasks.MAX_UNIQUE_FOR_CLASSIFICATION = 20

Maximum number of unique integer values for a target to be considered categorical (classification).

trainedml.tasks.detect_model_task(model, y=None) → str[source]

Determine the task type of a model, whatever it is.

Priority order:

  1. the model’s task attribute (trainedml models, BaseModel);

  2. scikit-learn’s is_classifier / is_regressor functions (arbitrary sklearn estimators);

  3. the heuristic on the y target, if provided.

Paramètres:

  • model (object) – trainedml model, scikit-learn estimator, or any fit/predict object.

  • y (array-like, optional) – Target, used as a last resort for the heuristic.

Renvoie:

'classification' or 'regression'.

Type renvoyé:

str

trainedml.tasks.detect_task(y) → str[source]

Return the task type associated with a target.

Paramètres:

y (pandas.Series or array-like) – Target column to analyze.

Renvoie:

'classification' or 'regression'.

Type renvoyé:

str

Exemples

>>> detect_task(pd.Series([0, 1, 2, 0, 1]))
'classification'
trainedml.tasks.is_classification_target(y) → bool[source]

Determine whether the target is categorical (classification) or numeric (regression).

Paramètres:

y (pandas.Series or array-like) – Target column to analyze.

Renvoie:

True if classification, False if regression.

Type renvoyé:

bool

Exemples

>>> is_classification_target(pd.Series(['cat', 'dog']))
True
>>> is_classification_target(pd.Series([0.1, 2.7, 3.14]))
False
