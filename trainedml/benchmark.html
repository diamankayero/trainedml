Benchmark

Benchmark utilities for comparing multiple models in trainedml.

This module provides the Benchmark class to compare the performance (accuracy, speed, etc.) of several models on the same dataset, with optional parallelization and progress bar.

Mathematical Formulation

Let $mathcal{M} = {M_1, …, M_K}$ be a set of models. For each model $M_k$: - Fit time: $T_{fit}^{(k)}$ - Predict time: $T_{pred}^{(k)}$ - Score: $S^{(k)}$ (e.g., accuracy)

The benchmark returns a dictionary:

{
    'model_name': {
        'scores': {...},
        'fit_time': ...,
        'predict_time': ...
    },
    ...
}

Exemples

>>> from trainedml.benchmark import Benchmark
>>> models = {'knn': KNNModel(), 'rf': RandomForestModel()}
>>> bench = Benchmark(models)
>>> results = bench.run(X_train, y_train, X_test, y_test)
>>> print(results)

run(X_train, y_train, X_test, y_test, parallel: bool = False, n_jobs: int = -1, show_progress: bool = True) → Dict[str, Dict][source]

Train and evaluate each model, returning scores and timing.

Paramètres:

  • X_train (array-like) – Data splits.

  • y_train (array-like) – Data splits.

  • X_test (array-like) – Data splits.

  • y_test (array-like) – Data splits.

  • parallel (bool, default=False) – If True, run models in parallel.

  • n_jobs (int, default=-1) – Number of jobs for parallelization.

  • show_progress (bool, default=True) – Show a progress bar.

Renvoie:

{model_name: {scores, fit_time, predict_time}}

Type renvoyé:

dict

run_cv(X, y, cv: int = 5, show_progress: bool = True, random_state: int = 42) → Dict[str, Dict][source]

Compare les modèles par validation croisée (K-fold).

Chaque modèle est entraîné et évalué sur cv plis ; les métriques retournées sont les moyennes sur les plis, avec l’écart-type dans scores_std. Pour la classification, les plis sont stratifiés.

Paramètres:

  • X (pandas.DataFrame or array-like) – Features (jeu complet, non splitté).

  • y (pandas.Series or array-like) – Cible.

  • cv (int, default=5) – Nombre de plis.

  • show_progress (bool, default=True) – Affiche une barre de progression.

  • random_state (int, default=42) – Graine pour le mélange des plis.

Renvoie:

{model_name: {“scores”: moyennes, “scores_std”: écarts-types, “fit_time”: temps moyen, “predict_time”: temps moyen, “cv”: cv}}

Type renvoyé:

dict

Exemples

>>> bench = Benchmark({'knn': KNNModel(), 'rf': RandomForestModel()})
>>> results = bench.run_cv(X, y, cv=5)
>>> print(bench.to_dataframe())

to_dataframe(sort: bool = True) → 'pd.DataFrame' | None[source]

Convertit les résultats du benchmark en DataFrame pandas.

Les colonnes sont les métriques (plus fit_time et predict_time), les lignes les modèles. Si les résultats proviennent de run_cv(), des colonnes <metric>_std sont ajoutées. Le tableau est trié par la métrique principale (accuracy ou r2), du meilleur au moins bon.

Paramètres:

sort (bool, default=True) – Trier par la métrique principale, décroissante.

Renvoie:

Tableau comparatif, ou None si run()/run_cv() n’a pas été exécuté.

Type renvoyé:

pandas.DataFrame or None

Exemples

>>> bench.run(X_train, y_train, X_test, y_test)
>>> df = bench.to_dataframe()
>>> print(df)
