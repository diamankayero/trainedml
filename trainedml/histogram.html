Histogram

Histogram visualization for trainedml.

This module provides the HistogramViz class, which generates histograms for one or more columns using matplotlib, supporting custom binning and legend options.

Exemples

>>> from trainedml.viz.histogram import HistogramViz
>>> viz = HistogramViz(df, columns=['A', 'B'])
>>> viz.vizs()
>>> viz.figure.show()
class trainedml.viz.histogram.HistogramViz(data: DataFrame, columns: str | List[str] = 'all', legend: bool = False, bins: int = 10, save_path: str | None = None)[source]

Bases : Vizs

Histogram visualization for one or more columns.

Paramètres:

  • data (pandas.DataFrame) – The dataset.

  • columns ('all' or list, default='all') – Columns to plot.

  • legend (bool, default=False) – Show legend if multiple columns.

  • bins (int, default=10) – Number of bins.
